# Custom Portfolio

A personal portfolio website for Thiago Silva, built as a responsive terminal-inspired static site. The project presents a concise professional profile, core strengths, portfolio links, and direct contact options.

## Overview

This portfolio is designed to be simple to deploy, fast to load, and easy to maintain. It uses plain HTML, CSS, and JavaScript, with no build step or framework dependency.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/thiiagoms/thiiagoms.github.io.git
cd thiiagoms.github.io
```

Open `index.html` in a browser. No package installation is required.
